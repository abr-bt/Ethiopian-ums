# Ethiopian Universities Management System

Full-stack starter project using:
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Local installation with XAMPP

1. Copy this folder to `C:\xampp\htdocs\`
2. Start Apache and MySQL in XAMPP.
3. Open `http://localhost/phpmyadmin`
4. Import `database/ethiopian_universities.sql`
5. Open `http://localhost/ethiopian-universities-management/`

## Important
This is a learning/demo management system. The displayed Ministry of Education administrator is a demo role, not an official government account.

## GitHub
Upload the entire folder to one GitHub repository. GitHub Pages cannot run PHP or MySQL; GitHub can store the source code, while PHP/MySQL hosting is required to run the full application online.
